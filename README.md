# 🚀 Startup Analytics Dashboard

A Machine Learning-powered Streamlit application built using the 50 Startups dataset.

## Features

### 📊 Interactive Dashboard

* Executive KPI Cards
* Startup Performance Overview
* Business Insights

### 🔍 Data Explorer

* Dataset Preview
* Statistical Summary
* Missing Value Analysis
* Correlation Analysis

### 📈 Deep Analytics

* Profit Distribution
* State-wise Profit Comparison
* R&D vs Profit Analysis
* Marketing Impact Analysis
* Correlation Heatmaps

### 🤖 Machine Learning

* Random Forest Regression Model
* Startup Profit Prediction
* Real-time User Inputs
* Prediction History Tracking

### 📄 Automated Reports

* Startup Summary Reports
* Business Insights Reports
* Top Performing Startups Reports
* Prediction Logs

## Installation

```bash
pip install -r requirements.txt
```

## Train Model

```bash
python train_model.py
```

## Run Application

```bash
streamlit run app.py
```

## Deployment

1. Push project to GitHub
2. Login to Streamlit Community Cloud
3. Connect GitHub repository
4. Select app.py
5. Deploy
